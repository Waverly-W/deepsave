# DeepSave Pro 产品需求文档（PRD）

## 1. 产品定位与愿景
DeepSave Pro 是面向 NAS 场景的本地优先知识中枢：以低成本采集、AI 结构化处理与混合检索为核心，帮助用户高效回看与再利用知识资产。

## 2. 目标用户与优先级
- P0 效率派：需要速度与隐私平衡的混合架构。
- P1 隐私极客：要求离线可用、本地推理。
- P2 开发者：偏好开放 API 与可扩展性。

## 3. MVP 范围（锁定）
**必须有**
- URL 采集：Web 端输入、浏览器扩展（Chrome/Edge）、剪贴板脚本。
- 智能爬虫：HTTP 优先，Playwright 兜底。
- 路由处理：文章/图片/代码三类。
- AI 结构化：摘要、标签、必要元数据。
- 混合检索：关键词 + 向量（RRF 融合）。
- Web 前端：搜索主页（概览统计/最近卡片/常用标签/最近搜索）+ 时间线；详情阅读页。
- 鉴权：单管理员账号 + JWT + Access Token。

**延后（Phase 2）**
- PDF/Office 解析、批量导入、移动端应用。
- 知识图谱与可视化。

**不做**
- 多人协作与 SaaS 化。

## 4. 成功指标（KPI）
- URL 正文提取成功率 > 95%（排除死链）。
- 处理时延：输入 URL 到生成卡片 < 15s（API 模式）。
- 检索召回：Top10 结果点击率 > 40%。

## 5. 功能需求摘要
- 采集：URL、图片链接、选中文本（扩展右键）。
- 处理：摘要 3 条要点、标签、情感（展示用）。
- 存储：PostgreSQL（关系+向量+检索）；资产落盘。
- 检索：标题/标签模糊匹配 + 正文检索 + 语义向量。
- 交互：列表无限滚动、详情阅读、归档/删除/重试。

## 6. 非功能性要求
- 单机低配可用（J4125/8GB）。
- 纯内网运行，默认不开公网。
- 数据本地化；API Key 本地加密存储。

## 7. 里程碑（参考）
- W1：基础容器与工程骨架。
- W2：爬虫与存储打通。
- W3：AI 处理 + 向量检索。
- W4：前端联调与收尾。
