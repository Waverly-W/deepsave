预计周期: 4周Stack: Next.js + FastAPI + SQLite.Core: 实现混合爬虫 (HTTP优先, Playwright兜底)。AI: 接入 OpenAI 接口作为默认 (快速启动)，预留 Ollama 接口。UI: 基于 shadcn/ui 搭建 Chat 和 列表页面。Phase 2: 本地化与视觉 (Hybrid 升级) - 预计周期: 6周Local LLM: 完整对接 Ollama，支持模型下拉选择。Vision: 集成 MiniCPM-V (本地) 和 GPT-4V (云端) 处理图片。Vector: 引入 ChromaDB 实现语义搜索。Phase 3: 主动性与体验 (唤醒与图谱) - 预计周期: 4周Recall: 开发“每日回顾”算法。Optimization: 针对 Next.js 进行移动端 PWA 适配。8. 风险评估 (Risks)依赖冲突：Python 后端 (FastAPI) 与 Node.js 前端 (Next.js) 需要在 NAS 上同时部署。对策：提供统一的 docker-compose.yml，一键拉起所有容器，屏蔽环境差异。API 成本失控：用户若大量存入图片并使用 GPT-4V，成本可能过高。对策：在设置中增加“Token 消耗预警”或默认优先使用本地小模型处理大量图片。爬虫失败率：部分网站反爬严格。对策：允许用户手动输入 Cookie 或 User-Agent 增强无头浏览器的伪装能力。
